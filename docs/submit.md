#### 我们为什么要做这个？

学校新值班员第一次遇到夜间宿舍火警时，最容易出错的往往不是“背不出预案”，而是**在高压和信息混杂下，分不清哪些上报是真的、哪些是误报/重复上报，又该先派谁、怎么疏散**。

* **传统痛点**：纸质预案是静态的，很难把“宿舍火灾 + 暴雨内涝”这类复合灾情演练透；老值班员的临场经验也难以沉淀，新人只能靠真实值班摸索。
* **校园场景还原**：地图基于**南京工程学院江宁校区**的 20 栋真实建筑名称与分区（如萃园、润园、学海苑等），让学员练到真正会听到的地名；同时建筑平面位置、容量与风险等级均为**训练级模拟设定**，非实测数据。
* **安全边界声明**：本系统**仅用于桌面推演训练**，不是实战指挥系统。首页及每条上报均明确标注：灾情与学生上报均为模拟数据，AI 输出仅供本轮推演讨论，与真实报警、监控、传感器及指挥通信渠道严格隔离，**最终决策始终归人**。

#### 用户应该怎么用这个平台？（免登录，5 步走通）

1. **进入沙盘**：打开公网链接，阅读首屏训练声明，点击“开始一次推演”。
2. **选择场景**：挑选一张预置场景卡，或点击“AI 随机生成”（每会话限 3 次）。
3. **边出边判**：信息流按时间轴分批出现模拟上报（每轮 10 条）。每条出现后即可判为“真报 / 误报 / 待核”**，也可为其选择楼栋位置或标记**“无法定位”，无需等整批刷完。
4. **临场处置**：点击楼栋，执行**派队、警戒、广播疏散**等 6 种动作，观察资源与路线变化；支持加速推进，也可随新线索改判并再次行动。
5. **排序与复盘**：末回合对整批上报做一次优先级排序，选出**最紧急的 3 条**。结束后立即查看分项得分、失误对应的动作与时间线，AI 点评异步补入；本轮记录自动留痕，可按编号导出 JSON 回看。

**一个小策略巧思**：面对证据不足的上报，最优解往往是“判待核 + 立即派核查动作”——既能拿稳甄别分，也能抢占响应速度分。

**平台的计分规则**：

* 上报甄别 **30%**
* 有效响应 **20%**
* 标准动作命中 **35%**
* 重复违规 **15%**
临场调整动作，得分会实时变化并给出可解释的失误定位。

**内置模板与案例**：

* **主场景**：夜间宿舍楼火灾与暴雨内涝
* **轻量模板**：实验室危化品泄漏与人员失联、体育馆散场踩踏风险与通讯中断
* **完整案例**：另备 2 个完整案例，免登录即可直接体验。
