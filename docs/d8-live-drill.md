## 单份导出复算

在仓库根目录运行，依赖已按 README 安装。输入是通过「导出本轮 JSON」保存的已结算轮次文件。工具复用 D6 `importRun` 校验冻结题目、流水、动作判定及评分缓存，再用当前规则引擎独立复算。退出 0 表示通过。核对 `score` 中的甄别 `discrimination`、响应 `response`、命中 `coverage`、合规 `violation` 及 `total`，然后按 `run_id` 和 `details` 的动作序号与录像对应。也可在「新开推演」后用页面的「独立核验轮次 JSON」做第二次核对。 [复算入口](../scripts/replay-run.ts) · [D6 导出走查](handoff-d6.md)

```powershell
npx --no-install tsx scripts/replay-run.ts "D:/保存位置/现场已结算轮次.json"
```

可复现的**固定演练样例**。目标必须是新文件；若已生成，第二条可直接使用已有文件。

```powershell
$sample = Join-Path $env:TEMP 'd8-rehearsal-jia.json'
npx --no-install tsx scripts/replay-run.ts --sample $sample
npx --no-install tsx scripts/replay-run.ts $sample
```

样例 `d8-example-run-jia-1x` 的 21 条事件复算为 **80 / 100 / 80 / 70 → 83**。第 1 条 A1 向 N7 提交于 T+30、完成于 T+75，距首报 45 秒。样例的 0 ms 是无真人操作的占位值，录像和学员反馈栏留给现场记录。 [实跑日志](qoder-evidence/d8-export-replay.log)
