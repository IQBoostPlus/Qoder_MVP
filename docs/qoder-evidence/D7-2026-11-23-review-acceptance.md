## 1. 复盘内容与冻结记录

- 既有四组样例重新计算为 **83 / 44 / 90 / 83**。点评前后的导出内容、Sites 独立 GET 与原冻结记录一致。点评只新增独立台账数据。
- Node 与 Sites 用同一组冻结案例复验。相同动作返回相同引用与文字，零动作走现有摘要且发送数不增加。
- 错轮次、错序号、虚构事件、错误分数、真实指挥措辞、非法结构分别触发回退。有事实支持的「本轮完成警戒后才提交疏散」通过。
- Sites 正常路由覆盖未同步 404、未登录 401、功能关闭回退。Node 用错轮次密钥返回 404。

## 2. 预算与读回

- SQLite 预占剧本、共享重试、上报三槽。首次点评是第 4 个发送，换 ID 和第 5 次均无新发送。未完成原请求不能重试。另测空共享槽并发只允许一条显式重试。
- Sites 替身用正常生成入口建原账本，学员轮次 ID 与生成根不同。页面传入调用次数 0，服务端仍得到生成和首次点评共 2 次，显式重试后 3 次，再请求不增加。读回保留 D6 快照。
- 模拟发送后结果未知时，恢复读取原 Session。可控时钟核对 8,000 ms 截止、超时只读查询、迟到回执不覆盖其他轮次，以及恢复成功后忽略仍处于 `pending` 的旧回执。
