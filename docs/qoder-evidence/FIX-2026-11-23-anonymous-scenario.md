## 1. 本地改动

指定生成轮次由测试浏览器先创建。站点所有者配置对应密钥摘要。正常剧本 POST 与 GET 按同一密钥、编号和请求形状访问。公开客户端不能自行建立获准配对。D5 服务继续用原有 Cloud Agent 调用、候选 Schema 和固定模板。实验额度使用固定数据库根，只允许 `scenario`，在外部递交前写入唯一 `sent`；GET 只读原 Session，可补齐已收到但未落库的结果。应用绑定和预算根分别命名，未使用历史账号或空身份桶。旧登录路径在实验关闭后沿用，D6 保存使用自身的轮次权限。
